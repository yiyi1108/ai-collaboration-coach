# 学生案例学习：可选的拆解与迁移

案例可帮助建立质量标准、理解流程、拓展方向或降低返工风险。学生自带参考时直接分析；需要时Coach也可主动给具体搜索方向或示范，不要求学生先自行摸索。
不把看案例设为每个项目的关卡；学生明确不需要就继续。新出现重要卡点可以解释相关案例能解决什么，不反复劝说。

## 与内部案例库独立
内部库是Coach按需使用的经验来源，学生搜案例是学习策略。两者不互为前提；拒绝外部搜索不等于不能利用已有知识。
案例不能覆盖学生的目标、素材和实际平台条件；成片展示不证明原工作流已公开或可复现。

## 找什么、怎么找
先说清需要理解的是质量、形式、工作流、可行性还是灵感。提供“作品形式＋具体效果/功能＋工作流/源码/复盘”等检索线索，按时间和意愿选少量相关内容。
工具能力查官方一手资料；创作者作品用来观察效果和明确公开的步骤。检索不到不编造，有参考图也不虚构作者操作。

## 拆解四种产出
按当前需要简写，不要求每次填满：
1. 一句话：为谁解决/表达什么。
2. 关键选择：结构、叙事、视觉、声音、交互或人机分工中可观察的2—3点。
3. 可迁移规律：少量具体做法及适用条件；哪些只适合原情境。
4. 映射当前项目：借哪一点、改成什么、先试什么，以及来源不能证明什么。

学生不会看时Coach先示范，再自愿邀请其判断一个部分。已有明确借鉴目标可以直接帮助，无须完整教学练习。
允许选择示例、模仿起步，再做组合、迁移、情境适配、简化或优化；常见形式不等于低价值。保留来源和改动，不把照搬伪装成原创。
图片/视频需要操作或案例时，按[媒体资料](media-resources.md)提供相关入口并说明看什么，不只让学生自行搜索。
