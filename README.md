# AI 协作与复盘 Coach

面向大一新生 AI 素养实践课的中文 Coach Skill。

帮助学生构思作品、选择路线、验证关键技术、处理实际卡点，并将真实协作经验整理为可复用的方法。适用于图片、视频、音乐与播客、前端应用、小游戏、Skill 和智能体等项目。

当前版本：**v0.2.0**。课程参赛定稿；代码与资源的验证范围见下文。

## 下载与安装

从右侧 **Releases** 获取最新版安装包 `ai-collaboration-coach.zip`；参赛复现请选择 **v0.2.0**。

[最新版安装包](https://github.com/yiyi1108/ai-collaboration-coach/releases/latest/download/ai-collaboration-coach.zip) · [版本列表](https://github.com/yiyi1108/ai-collaboration-coach/releases)

下载入口在维护者创建 Release 并上传安装包后生效。

1. 解压后保留完整的 `ai-collaboration-coach` 文件夹。
2. 在支持 Skill 的平台中，按其导入方式加载该文件夹或 ZIP；入口为 `SKILL.md`。
3. 不要只复制主文件：`references`、`assets`、`scripts` 与 `licenses` 需保留。
4. 核对已加载版本为 v0.2.0，再提出具体任务。

仅支持普通对话的平台，可以使用 [便携核心提示](ai-collaboration-coach/PORTABLE_PROMPT_ZH.md)，并按需补充方法文件；便携版不等于完整安装版。不同平台的文件读取、生成、联网及代码执行能力不同，不能保证所有平台具有相同效果。

不需要学生开通 GitHub 账号才能下载公开发布包。GitHub 负责源码和文件分发，实际使用发生在学生选择的大模型平台中。

## 可以这样开始

- “我没想法，喜欢摄影和推理，请帮我找一个适合小规模尝试的方向。”
- “我已经确定做这个，请先帮我处理最关键的实现问题。”
- “这是另一工具给的结果，与预期有这些差别，请帮我判断下一步。”
- “项目暂时到这里，请生成 AI 协作报告。”

## 协作报告

默认中文 MD 详细报告＋固定模板 HTML 视觉摘要。结合可见记录和必要访谈整理事实，默认确认 MD 后继续生成 HTML；可以明确要求同轮两份或仅一种格式。

报告包括作品与需求、关键过程与证据、人与 AI 的作用和边界、可带走的方法。不会自动读取其他工具中的全部对话，也不能代替教师对学习情况的判断。
